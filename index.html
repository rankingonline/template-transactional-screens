02 · Paleta

Una paleta, siete temas

Cada hue tiene escala 50–900. Las secciones aplican un tema con la clase theme-{nombre} y reciben automáticamente la sub-escala correcta.

Purple theme-purple
Crimson theme-crimson
Indigo theme-indigo
Steel theme-steel
Gold theme-gold
Teal theme-teal
Forest theme-forest
03 · Tipografía

Cuatro sets tipográficos

Aplicá font-set-1 a font-set-4 en <body> o en una <section>.

Set 01 · Moderno neutral

DM Sans + Inter

Sobrio y profesional. Para tech / consultoría como Sol-4 o Consulting-F.

Set 02 · Elegante editorial

Playfair + Inter

Autoridad legal. Para Romero Martínez, Barreda Díaz o Aselegal.

Set 03 · Humanista cálido

Nunito Sans

Cercano y empático. Para Medalva o Christian Sánchez.

Set 04 · Display contemporáneo

Space Grotesk + IBM Plex

Tech-forward. Para Tribulex, Ecom Advisory o Segu Web.
